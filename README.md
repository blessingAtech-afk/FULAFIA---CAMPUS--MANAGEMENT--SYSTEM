# FULAFIA Campus Management System

A Java-based campus management application developed as a practical programming project.

## About the Project

The FULAFIA Campus Management System is a desktop application designed to demonstrate how a simple campus management system can be developed using Java.

The project provides a structured way to manage student information through a user-friendly interface.

## Technologies Used

- Java
- IntelliJ IDEA
- Java Swing
- File Handling

## Main Features

- User login
- Dashboard
- Student record management
- Add student records
- View student records
- Search student records
- Update student records
- Delete student records
- Data storage using files

## Purpose

This project was developed as a practical Java programming project to strengthen my understanding of object-oriented programming, file handling, user interfaces, and application development.
